# 清理与收口（P3）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 8 个真实任务 + 3 示例已全部改用新门面后，删除旧扁平方法、拟人层（`Humanizer`/`ghost-cursor`）与打码插件路线（仅保留 Turnstile 方框点击），并把 `tasks`/`engine` 的引用收口到 barrel。

**Architecture:** 纯删除/收口，不改新门面行为。旧方法删净后 `TaskContext` 只剩：`page/log/profile/account/accountRow/uploadFile/js/screenshot/safeScreenshot` + `wallet.*/captcha.*/step/steps/race/recover`。`TaskContextDeps` 去掉 `human`。打码插件路线全删（含配置/接口/前端余量）。

**Tech Stack:** TypeScript（严格）、patchright、vitest、React/Vite（web）。

## Global Constraints

- 依赖方向：`tasks → engine → automation/integrations → infrastructure`，不可反向。
- 每个 automation 子目录一个 `index.ts` 统一出口；目录外只从 barrel 导入。
- 代码风格：无分号、单引号、2 空格缩进；文件头中文注释块。
- 验证：`npm run typecheck`、`npm test`、`npm run test:web`（涉及 web 时）。
- 提交风格：conventional + 中文，单行。
- 运行环境：Windows PowerShell 5.1；分支 `feat/task-thin-facade`。
- 文档同步（API-GUIDE 删除被删方法/第 12 章）在 Plan 5 统一处理；本计划不含文档。
